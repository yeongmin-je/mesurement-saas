# 01. Product Requirements Document (PRD)

## 1. 제품 개요

**제품명**: MetroAI
**한 줄 정의**: 사진 한 장으로 측정기를 등록하고, AI가 교정 주기를 자동 관리하는 한국형 SaaS
**버전**: 0.1.0 (Phase 1 MVP)

## 2. 비전과 미션

### 2.1 비전
한국 중소 제조사·연구실·식품공장의 계측기 관리를 종이와 엑셀에서 해방시켜, AI로 자동화된 품질관리 시대를 연다.

### 2.2 미션
모든 측정기가 자기 상태를 알리는 세상. 사용자는 사진만 찍으면 끝.

## 3. 해결하는 문제

### 3.1 현재의 문제

| 문제 | 영향 |
|---|---|
| 측정기 등록이 수작업 (제조사·모델·시리얼 직접 입력) | 등록당 5~10분, 1,000대면 일주일 |
| 교정 만료일을 엑셀로 관리 | 누락 35% 발생 (전력설비 기준) |
| 만료된 계측기로 측정하면 법적 효력 상실 | ISO·HACCP 부적합 |
| 종이 성적서가 캐비닛에 쌓임 | 심사 때마다 며칠 뒤짐 |
| 글로벌 SaaS는 연 수천만 원 | 중소기업 진입 불가 |

### 3.2 시장 빈틈

- **글로벌**: Beamex CMX, ComplianceQuest 등은 가격 비싸고 한국 KOLAS 양식 미지원
- **국내**: Open Solution ERP 등 ERP 모듈은 ERP 전체 도입 필요
- **AI**: 사진 한 장 등록은 글로벌 어디에도 없음

## 4. 타깃 사용자

### 4.1 1차 타깃 (Phase 1)

**페르소나 A: 식품공장 품질관리자 (40대)**
- 보유 측정기 50~300대 (저울, 온도계, pH미터 등)
- ISO 22000, HACCP 인증 필수
- 현재 엑셀 + 종이 라벨로 관리
- 페인포인트: 심사 일주일 전 야근

**페르소나 B: 중소 제조사 품질팀장 (30~40대)**
- 보유 측정기 100~1,000대 (캘리퍼, 마이크로미터, 압력계 등)
- ISO 9001 인증 보유
- 현재 자체 엑셀 시스템
- 페인포인트: 교정 만료 누락, 부서간 정보 공유 어려움

**페르소나 C: 연구실 행정담당 (20~30대)**
- 보유 측정기 20~100대 (실험 장비 다양)
- KOLAS 인증은 아니지만 정기 교정 필요
- 현재 거의 관리 안 함
- 페인포인트: 누가 어디 사용 중인지 모름

### 4.2 2차 타깃 (Phase 2+)

- KOLAS 공인 교정기관 (200~300곳) → 마켓플레이스 공급 측
- 병원·연구기관 (의료기기 교정 SKU)

## 5. 핵심 가치 제안

```
30초만에 사진 한 장으로 등록
AI가 KOLAS 568종에서 자동 매칭
카카오톡으로 만료 알림
ISO 심사 보고서 원클릭
```

가격: 월 3만원부터 시작 (5~20대 기준)

## 6. 성공 지표 (KPI)

### 6.1 Phase 1 출시 후 3개월 KPI

| 지표 | 목표 |
|---|---|
| 가입 사업장 | 100곳 |
| 등록 측정기 | 5,000대 |
| 사진 등록 정확도 | 95% (사용자 수정 없이 통과) |
| 평균 등록 시간 | 60초 이하 |
| 알림 → 교정 전환율 | 70% |
| 월간 활성 사용자 (MAU) | 200명 |

### 6.2 Phase 1 출시 후 6개월 KPI

| 지표 | 목표 |
|---|---|
| 유료 전환 사업장 | 30곳 (월 3만원~) |
| 월 매출 | 200만원 |
| NPS (순추천 지수) | 40 이상 |
| 이탈률 | 월 5% 이하 |

## 7. 범위 (Scope)

### 7.1 Phase 1 포함

- 사진 등록 (Vision AI + 드롭다운 확정)
- 측정기 CRUD, 검색, 필터, 상세
- 부서·위치·담당자 관리
- KOLAS 568종 자동 매칭
- 교정 주기 자동 계산
- 교정 이력 수동 입력
- 만료 알림 (앱 푸시, 카톡, SMS)
- 기본 대시보드
- ISO 9001/17025 심사 대응 보고서 (PDF)
- 모바일 앱 (등록 + 조회)
- 웹 앱 (관리 + 분석)

### 7.2 Phase 1 제외 (Out of Scope)

- 교정기관 마켓플레이스
- 성적서 OCR 자동 추출
- 일일점검 자동 기록
- IoT 환경 보상
- SIMS 저울 자가진단 연동
- 다국어 (한국어만)
- 결제/구독 결제 시스템 (Phase 1 후반에 추가)
- AI 주기 최적화 (KOLAS 표준만 사용)

## 8. 제약 조건

### 8.1 기술 제약

- 인터넷 필수 (오프라인 등록은 Phase 2)
- 사진 1장당 Vision API 비용 약 50~100원
- 동시 사용자 1,000명까지는 단일 서버 가능

### 8.2 법규 제약

- 개인정보보호법: 사용자 이메일·전화번호 암호화
- 측정기 사진은 사업장 자산이므로 별도 동의 불필요
- KOLAS 표준주기 데이터는 공개 자료 사용 가능

### 8.3 사업 제약

- 초기 6개월은 무료/저가로 데이터 축적 우선
- SIMS 고객사부터 베타 풀기

## 9. 가정과 리스크

### 9.1 가정

- Claude Vision API는 측정기 명판 인식에 충분한 정확도 제공
- 한국 주요 제조사 30곳의 모델 정보를 6개월 내 마스터 DB로 구축 가능
- 영민님 SIMS 고객사 중 50% 이상이 베타 참여 의향

### 9.2 리스크

| 리스크 | 영향도 | 대응 |
|---|---|---|
| Vision AI 정확도 80% 미만 | 높음 | 드롭다운 fallback으로 대체 가능 |
| KOLAS DB 구축 지연 | 중간 | 카테고리별 점진적 출시 |
| 알림톡 비용 폭증 | 중간 | 등급별 알림 횟수 제한 |
| 경쟁사 진입 (Beamex 한국화) | 낮음 | 가격 + 모바일 우선으로 차별화 |

## 10. 의존성

### 10.1 외부 서비스

- **Claude Vision API**: 측정기 인식
- **AWS S3**: 사진 저장
- **카카오 알림톡**: 비즈니스 메시징
- **Twilio**: SMS 백업
- **NextAuth**: 인증

### 10.2 내부 자산

- **SIMS 저울 인프라**: Phase 3 연동 예정
- **PostgreSQL 운영 경험**: SIMS와 공유
- **고객사 네트워크**: 베타 사용자 풀
